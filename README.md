# FPGA Jump Game

เกมวิ่งกระโดดหลบสิ่งกีดขวางที่เขียนด้วย Verilog สำหรับ FPGA แสดงผล VGA ความละเอียด 640×480 และควบคุมผ่าน Gamepad Pmod

## รูปแบบการเล่น

- สิ่งกีดขวางสลับระหว่างแบบอยู่บนพื้นและแบบลอย
- ตัวละครมีแอนิเมชันวิ่ง กระโดด และสไลด์
- เมื่อชนสิ่งกีดขวาง เกมจะหยุดและแสดงหน้าจอ `YOU LOSE`

| ปุ่ม | การควบคุม |
| --- | --- |
| **Up** | กระโดดข้ามสิ่งกีดขวางบนพื้น |
| **Down** | กดค้างเพื่อสไลด์ลอดสิ่งกีดขวางลอย |
| **Start** | เริ่มเกมใหม่หลัง Game Over |

## อุปกรณ์

- บอร์ด FPGA
- จอภาพที่รองรับ VGA
- TinyVGA Pmod หรือพอร์ต VGA บนบอร์ด
- Gamepad Pmod และจอยเกมที่รองรับ

## การเชื่อมต่อ Gamepad Pmod

| สัญญาณ | พอร์ต |
| --- | --- |
| Data | `ui_in[6]` |
| Clock | `ui_in[5]` |
| Latch | `ui_in[4]` |

สัญญาณ TinyVGA ถูกส่งออกทาง `uo_out[7:0]`

## ไฟล์หลัก

- `tt_um_vga_example.v` — ลอจิกเกม ตัวละคร การชน และภาพ VGA
- `gamepad_pmod.v` — อ่านและถอดรหัสข้อมูลจาก Gamepad Pmod
- `hvsync_generator.v` — สร้างสัญญาณ VGA 640×480
- `top_FPGA.v` — เชื่อมโมดูลเกมเข้ากับพอร์ตของบอร์ด FPGA

## การใช้งาน

สำหรับระบบที่ใช้รูปแบบพอร์ต Tiny Tapeout ให้ตั้ง `tt_um_vga_example` เป็น top module

หากใช้ `top_FPGA` ให้สร้าง Vivado Clocking Wizard ชื่อ `clk_wiz_0` เพื่อแปลง clock 100 MHz เป็น pixel clock 25 MHz จากนั้นจึงสังเคราะห์และโปรแกรมลงบอร์ด
