# FPGA Jump Game

เกมกระโดดหลบสิ่งกีดขวางที่เขียนด้วย Verilog สำหรับ FPGA แสดงผลภาพผ่าน VGA และควบคุมด้วย Gamepad Pmod

## ความสามารถ

- แสดงผลเกมที่ความละเอียด 640×480 ผ่าน TinyVGA Pmod
- กดปุ่ม **Up** เพื่อกระโดดหลบสิ่งกีดขวาง
- ตรวจจับการชนและแสดงหน้าจอ Game Over
- กดปุ่ม **Start** เพื่อเริ่มเล่นใหม่

## อุปกรณ์ที่ใช้

- บอร์ด FPGA หรือแพลตฟอร์มที่รองรับรูปแบบพอร์ตของ Tiny Tapeout
- TinyVGA Pmod และจอภาพที่รองรับ VGA
- Gamepad Pmod พร้อมจอยเกมที่รองรับ

## การเชื่อมต่อ Gamepad Pmod

| สัญญาณ | พอร์ต |
| --- | --- |
| Data | `ui_in[6]` |
| Clock | `ui_in[5]` |
| Latch | `ui_in[4]` |

สัญญาณ VGA ถูกส่งออกทาง `uo_out[7:0]` ตามรูปแบบขาของ TinyVGA Pmod

## ไฟล์หลัก

- `project.v` — ลอจิกเกม การเคลื่อนที่ การชน และการแสดงผล VGA
- `gamepad_pmod.v` — อ่านและถอดรหัสข้อมูลจาก Gamepad Pmod

## การนำไปใช้งาน

เพิ่มไฟล์ Verilog ทั้งสองไฟล์ลงในโปรเจกต์ FPGA แล้วตั้ง `tt_um_vga_example` เป็น top module ก่อนสังเคราะห์และโปรแกรมลงบอร์ด

> โปรเจกต์นี้เรียกใช้โมดูล `hvsync_generator` สำหรับสร้างสัญญาณ VGA ซึ่งต้องเพิ่มเข้ามาแยกต่างหากก่อนสังเคราะห์
