# FPGA Jump Game

เกมวิ่งกระโดดหลบสิ่งกีดขวางที่เขียนด้วย Verilog สำหรับ FPGA แสดงผล VGA ความละเอียด 640×480 และควบคุมผ่าน Gamepad Pmod

## Describe Your Project

โปรเจกต์นี้เป็นเกมแนว endless runner บน FPGA ผู้เล่นต้องเลือกกระโดดหรือสไลด์ให้ถูกจังหวะเพื่อหลบสิ่งกีดขวางที่เคลื่อนเข้ามาจากด้านขวา ตัวเกมทำงานด้วยวงจรดิจิทัลในภาษา Verilog ตั้งแต่การอ่านปุ่ม การคำนวณฟิสิกส์ การตรวจจับการชน ไปจนถึงการวาดภาพบนจอ VGA โดยไม่ใช้ CPU หรือ game engine

รูปแบบการเล่นได้รับแรงบันดาลใจจาก **Cookie Run** ซึ่งเน้นการวิ่งต่อเนื่องและตอบสนองต่อสิ่งกีดขวางอย่างรวดเร็ว โปรเจกต์นี้เป็นผลงานเพื่อการศึกษาและไม่มีความเกี่ยวข้องอย่างเป็นทางการกับผู้พัฒนา Cookie Run

## รูปแบบการเล่น

- สิ่งกีดขวางสลับระหว่างแบบอยู่บนพื้นและแบบลอย
- ตัวละครมีแอนิเมชันวิ่ง กระโดด และสไลด์
- เมื่อชนสิ่งกีดขวาง เกมจะหยุดและแสดงหน้าจอ `YOU LOSE`

| ปุ่ม | การควบคุม |
| --- | --- |
| **Up** | กระโดดข้ามสิ่งกีดขวางบนพื้น |
| **Down** | กดค้างเพื่อสไลด์ลอดสิ่งกีดขวางลอย |
| **Start** | เริ่มเกมใหม่หลัง Game Over |

## Game Logic

1. Clock 25 MHz ถูกหารลงเป็น `game_tick` ประมาณ 25 ครั้งต่อวินาที เพื่อกำหนดจังหวะอัปเดตเกม
2. ตัวละครอยู่กับที่ทางแกน X ส่วนสิ่งกีดขวางเคลื่อนจากขวาไปซ้าย ทำให้ดูเหมือนตัวละครกำลังวิ่งไปข้างหน้า
3. เมื่อกด **Up** ขณะอยู่บนพื้น ตัวละครจะได้รับความเร็วขึ้นด้านบน จากนั้นแรงโน้มถ่วงจะเพิ่มความเร็วลงจนกลับถึงพื้น
4. เมื่อกด **Down** บนพื้น ตัวละครจะเปลี่ยนเป็นท่าสไลด์และลดความสูงของ hitbox เพื่อให้ลอดสิ่งกีดขวางลอยได้
5. เมื่อสิ่งกีดขวางพ้นขอบจอ จะกลับไปเริ่มทางด้านขวาและสลับระหว่างแบบพื้นกับแบบลอย
6. ระบบตรวจชนเปรียบเทียบขอบเขตของตัวละครกับสิ่งกีดขวาง หากพื้นที่ซ้อนกันจะตั้งสถานะ `game_over` และหยุดการเคลื่อนที่
7. ปุ่ม **Start** จะรีเซ็ตสถานะเกม ตำแหน่งตัวละคร และตำแหน่งสิ่งกีดขวางเพื่อเริ่มเล่นใหม่
8. เฟรมแอนิเมชันจะสลับตามจังหวะเกม และเลือกภาพตัวละครให้ตรงกับสถานะวิ่ง กระโดด หรือสไลด์

## อุปกรณ์

- บอร์ด FPGA
- จอภาพที่รองรับ VGA
- TinyVGA Pmod หรือพอร์ต VGA บนบอร์ด
- Gamepad Pmod และจอยเกมที่รองรับ

## การเชื่อมต่อ Gamepad Pmod

| สัญญาณ | พอร์ต |
| --- | --- |
| Data | `ui_in[6]` |
| Clock | `ui_in[5]` |
| Latch | `ui_in[4]` |

สัญญาณ TinyVGA ถูกส่งออกทาง `uo_out[7:0]`

## ไฟล์หลัก

- `tt_um_vga_example.v` — ลอจิกเกม ตัวละคร การชน และภาพ VGA
- `gamepad_pmod.v` — อ่านและถอดรหัสข้อมูลจาก Gamepad Pmod
- `hvsync_generator.v` — สร้างสัญญาณ VGA 640×480
- `top_FPGA.v` — เชื่อมโมดูลเกมเข้ากับพอร์ตของบอร์ด FPGA

## การใช้งาน

สำหรับระบบที่ใช้รูปแบบพอร์ต Tiny Tapeout ให้ตั้ง `tt_um_vga_example` เป็น top module

หากใช้ `top_FPGA` ให้สร้าง Vivado Clocking Wizard ชื่อ `clk_wiz_0` เพื่อแปลง clock 100 MHz เป็น pixel clock 25 MHz จากนั้นจึงสังเคราะห์และโปรแกรมลงบอร์ด
